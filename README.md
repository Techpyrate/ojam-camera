# OJAM Camera

Puts your live [ojam.online](https://ojam.online) Studio stage on a real Windows webcam called **OJAM Camera**. Use it in Zoom, Teams, Google Meet, Discord, OBS and more.

**[Download for Windows](https://github.com/Techpyrate/ojam-camera/releases/latest/download/OJAM-Camera-Setup.exe)**

1. Install and open OJAM Camera.
2. In ojam.online Studio, click **Virtual Cam** in the top bar.
3. Pick **OJAM Camera** as your webcam in any app.

The camera driver is built on [softcam](https://github.com/tshino/softcam) (MIT License).
